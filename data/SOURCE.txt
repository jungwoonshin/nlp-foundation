Dataset: text8 (first 1,000,000 words)

The original word2vec papers trained on Google News (about 6B–100B tokens),
which is not publicly available. The official word2vec toolkit instead ships
a demo that downloads text8, a small cleaned Wikipedia corpus from Matt
Mahoney used as the public stand-in for experiments:

  http://mattmahoney.net/dc/text8.zip
  http://mattmahoney.net/dc/textdata.html
  https://github.com/tmikolov/word2vec/blob/master/demo-word.sh

text8 is the first 100MB of processed English Wikipedia (17,005,207 words).
text8m1.txt is the first 1,000,000 words of that file (~5.9MB, 52,754 types),
kept small enough to store in git.

AG News is the smallest / easiest set in Joulin et al., "Bag of Tricks
for Efficient Text Classification" (Zhang et al. 2015 split): 120,000
train docs, 4 classes. `python prepare.py fasttext` (or `python train.py fasttext`)
downloads the public train.csv into data/raw/ and writes one FastText
line per article to data/ag_news.txt (`__label__<1-4> tokens...`).
Newlines separate documents; the leading `__label__` token is the class
(1 World, 2 Sports, 3 Business, 4 Sci/Tech) and is not part of the vocab.

The zip, full text8, and questions-words.txt live in data/raw/ (gitignored).
To restore them:

  python prepare.py word2vec

or:

  curl -L -o data/raw/text8.zip http://mattmahoney.net/dc/text8.zip
  python -c "import zipfile; zipfile.ZipFile('data/raw/text8.zip').extractall('data/raw')"
  curl -L -o data/raw/questions-words.txt https://raw.githubusercontent.com/tmikolov/word2vec/master/questions-words.txt

IWSLT'15 English–Vietnamese is the smallest public set used with Luong et al.
(2015) attention NMT (Stanford NMT page, [Small]; the EMNLP paper itself
trains on WMT'14 En–De). `python prepare.py luong_attention` writes the
already-tokenized TED splits into data/raw/iwslt15.en-vi/:

  https://nlp.stanford.edu/projects/nmt/data/iwslt15.en-vi/

If Stanford returns 403, the same files are fetched from the PaddleNLP mirror:

  https://bj.bcebos.com/paddlenlp/datasets/iwslt15.en-vi.tar.gz

  train.en / train.vi   (~133K pairs)
  tst2012.en / tst2012.vi   (dev)
  tst2013.en / tst2013.vi   (test)
  vocab.en / vocab.vi

The raw files are gitignored via data/raw/.
